# THROW
A simple browser-based html game that is subjected around rock, paper, scissors. It has online multiplayer capabilities with custom matchmaking and room specific leaderboards.

# How to Install/Play
Press 'Code', then 'Download ZIP', then, once the zip has been downloaded, unzip it or extract it and open the throw.html. It will open the game in a new tab in your default browser. I included the other ZIP in case you want to make your life harder.

# How It Works
Basically, it's just online multiplayer rock paper scissors. It's quite fun.
